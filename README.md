# 🛒 বাজার দর (BazarDor)

দেশের নিত্যপ্রয়োজনীয় পণ্যের বাজার দর এক নজরে যাচাই করার জন্য একটি আধুনিক ওয়েব প্ল্যাটফর্ম।

## 🚀 প্রযুক্তিসমূহ (Technologies Used)
- **Framework**: Next.js 15 (App Router - JavaScript)
- **Styling**: Tailwind CSS + HeroUI
- **Authentication**: BetterAuth (Email/Password, Google & GitHub)
- **Toast Notification**: React Hot Toast

## ✨ মূল ফিচারসমূহ (Key Features)
1. **লাইভ প্রাইজ ট্র্যাকার (Price Marquee Ticker)**: স্ক্রিনের শীর্ষে বাজার দরের রিয়েল-টাইম লাইভ পরিবর্তন দেখতে পাওয়ার সুবিধা।
2. **দৈনিক পরিবর্তন (Risings & Fallings)**: দাম বৃদ্ধি পাওয়া ও কমা পণ্যগুলোর আলাদা ট্র্যাকিং সেকশন।
3. **বাংলা নিউমেরিক সর্টিং (Bengali Dynamic Sorting)**: পণ্যমূল্য অনুযায়ী কম থেকে বেশি বা বেশি থেকে কম বাংলা সংখ্যায় সাজানোর সুবিধা ।
4. **সুরক্ষিত প্রোডাক্ট বিস্তারিত তথ্য (Protected Details)**: লগইন ব্যবহারকারীদের জন্য বাজারভিত্তিক দামের সর্বনিম্ন, সর্বোচ্চ ও গড় মূল্য বিশ্লেষণ।
5. **প্রোফাইল তথ্য আপডেট (Update User Profile)**: BetterAuth ব্যবহার করে একাউন্টের নামসহ অন্যান্য তথ্য সহজেই আপডেট করার সুবিধা ।
